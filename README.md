# Locadora

Projeto de uma locadora fictícia de filmes para maiores de 18 anos, feito para a disciplina de Desenvolvimento Web I.

## Para abrir

Abra o arquivo `index.html` no navegador. É preciso estar conectado à internet para carregar o Bootstrap.

## Arquivos

- `index.html`: conteúdo do site.
- `css/style.css`: estilos.
- `js/main.js`: comportamento do menu em celulares.

O projeto será desenvolvido em etapas. Cadastros e locações serão adicionados depois.
